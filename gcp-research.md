# Google Cloud Platform (GCP)

## Brief Overview
Google Cloud Platform (GCP) is Google's cloud computing service, launched in 2008. It provides infrastructure services, platform services, and serverless computing environments. GCP is built on Google's internal infrastructure and is particularly strong in data analytics and machine learning.

## Global Infrastructure
GCP operates in 35+ regions and 100+ zones worldwide. It also has over 140 network edge locations. Google's global fiber network connects all regions, providing low-latency connectivity.

## Cloud Management Console
The Google Cloud Console is a web-based interface for managing GCP resources. It allows users to view, manage, and monitor their cloud resources. The console also provides access to Cloud Shell, a browser-based terminal.

## Four (4) Core Services
1. **Compute Engine** - Scalable virtual machines on Google's infrastructure
2. **Cloud Storage** - Object storage with strong consistency
3. **Cloud SQL** - Managed relational database
4. **Cloud Identity and Access Management** - Resource management and access control

## Three (3) Advantages
1. **Data and Analytics** - Industry-leading analytics and BigQuery
2. **Machine Learning** - AI and ML capabilities using Google's TensorFlow
3. **Kubernetes Expertise** - Home of Kubernetes; best-in-class container management

## Typical Enterprise Use Cases
- Big data processing and analytics
- Machine learning and AI development
- Containerized applications with Kubernetes
- Open-source development workloads
