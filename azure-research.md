# Microsoft Azure

## Brief Overview
Microsoft Azure is Microsoft's cloud computing platform, launched in 2010. It provides a wide range of cloud services including computing, analytics, storage, and networking. Azure is particularly strong in hybrid cloud solutions and integrates seamlessly with Microsoft's ecosystem of products.

## Global Infrastructure
Azure operates in 60+ regions worldwide, spanning 140+ countries. It has more global regions than any other cloud provider. Each region contains multiple Availability Zones with independent power, cooling, and networking.

## Cloud Management Console
The Azure Portal is a web-based unified console that provides an alternative to CLI tools. Users can build, manage, and monitor everything from simple web apps to complex cloud deployments. The portal also offers role-based access control and cost management tools.

## Four (4) Core Services
1. Virtual Machines - On-demand Windows and Linux virtual machines
2. Blob Storage - Object storage for unstructured data
3. Azure SQL Database - Managed relational database service
4. Azure Active Directory - Identity and access management service

## Three (3) Advantages
1. Microsoft Integration - Seamless integration with Windows Server, SQL Server, and Microsoft 365
2. Hybrid Capabilities - Best-in-class hybrid cloud solutions
3. Enterprise Friendly - Strong enterprise agreements and support

## Typical Enterprise Use Cases
- Windows workloads and SQL Server migration
- Microsoft 365 integration and extension
- Enterprise identity management
- Hybrid cloud scenarios
