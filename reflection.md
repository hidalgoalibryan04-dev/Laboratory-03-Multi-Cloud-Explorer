Reflection

This mission was a great learning experience for me. Before this activity, I only knew cloud platforms by name. I heard about AWS, Azure, and GCP but I never really understood what made them different or why companies choose one over the other. Now after doing this research and comparing their services, I finally have a clearer picture of how cloud computing works in the real world.

GCP is the platform that impressed me the most. I liked how user-friendly it is. The Cloud Shell feature is really helpful because I can practice Linux commands directly in the browser without installing anything. I also noticed that GCP seems to be really strong in machine learning and data analytics, which is something I find interesting as an IT student. However, I know that being "impressive" doesn't mean it's always the right choice.

When I compared AWS, Azure, and GCP, I noticed they are actually very similar in many ways. They all have virtual machines, storage services, identity management, and databases. They all use a pay-as-you-go model and have data centers around the world. The main difference is the names they use for their services and some specific features they focus on. AWS has the most services, Azure works best with Microsoft products, and GCP is strong in data and AI. But the basic idea is the same across all of them.

One important thing I learned is that choosing a cloud provider is not about picking the "best" one. It's about understanding what the client needs. A startup with a small budget might prefer GCP because of its pricing and free credits. A company that already uses Windows and Microsoft 365 would be better off with Azure. A big company with complex needs might go with AWS because it has so many services available. This activity taught me to think about the client's situation first before making a recommendation.

Acting like a cloud consultant was challenging but fun. I had to think about business problems instead of just technical features. I learned that being a good cloud engineer means understanding what the customer actually needs and finding the right solution for them. I also got better at matching services across different platforms, which I think is a useful skill for real-world work.

My GitHub portfolio also improved a lot from this mission. I now have a proper folder structure with organized files. I learned how to write Markdown documents with headings, tables, and screenshots. This makes my repository look clean and professional. I think having this portfolio will help me when I apply for jobs or internships because employers can actually see the work I've done.

Overall, this mission helped me understand cloud platforms better and made me more confident in analyzing and recommending cloud solutions. I'm excited to learn more about cloud computing in the future.
